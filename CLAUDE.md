# Проект: сайт «Формирование многоконтурной площадки КРТ» (Чита)

## Перед любой работой
1. Прочитай `docs/ARCHITECTURE.md` целиком. Это источник правды об архитектуре,
   контракте данных, правилах расчёта и открытых вопросах.
2. Не пересматривай закрытые решения из раздела 14 «Решения» без явной просьбы пользователя.

## После любого изменения
- Изменилась архитектура, контракт JSON, правило расчёта, структура папок,
  появилось решение или закрылся открытый вопрос → обнови `docs/ARCHITECTURE.md`:
  нужный раздел, таблицу «Решения» (если это решение), строку в «Журнал изменений»
  с датой, дату «Последнее обновление» в шапке.
- Мелкие правки кода без влияния на архитектуру документ не требуют.

## Неприкасаемое
- Методика оптимизации и принятый набор комбинаций закрыты. `krt_optimizer/` и
  `output/KRT_оптимизация_результат.xlsx` не меняются. Последний пересчёт набора —
  2026-09-30 по решению заказчика (24.1 стала опорной, ARCHITECTURE.md, 14).
- Формулы расчёта одной комбинации живут в двух местах: `krt_optimizer/models.py`
  и `web/js/domain/combo.js`. Меняются только вместе, с обновлением golden-тестов.
- Оптимизация выбора (ARCHITECTURE.md, 3.6) — тоже пара: `web/js/domain/optimize.js`
  и эталон `tools/optimize_reference.py`. Меняются только вместе.
- Проверка `IP > 1` только в целых числах (см. ARCHITECTURE.md, 3.2).
- Скоринговая модель (ARCHITECTURE.md, 16): алгоритмы `web/js/scoring/model.js` и
  `scoring/crt_pipeline.py` закрыты. Меняются только вместе с пересъёмом эталона
  `tests/scoring_golden.json`. Исходные GPKG в `scoring/` не редактируются руками.

## Скиллы проекта (`.claude/skills/`)
- `krt-web-security` — перед любым кодом, который трогает DOM, URL, загрузку данных, nginx.
- `krt-clean-code` — при написании и ревью любого кода сайта и скриптов сборки.
- `krt-ui-design` — при любой вёрстке и стилях: токены, компоненты, форматы чисел.
- `frontend-design` (официальный от Anthropic) — общие принципы визуального дизайна.
  Визуальный язык прототипа из `krt-ui-design` имеет приоритет.
- Встроенные: `/security-review` перед выкладкой, `/code-review` и `/simplify` после
  крупных изменений.

## Окружение
- Windows, Python 3.13 в `.venv` (pandas, openpyxl, ortools). Node.js не установлен:
  нужен только для JS-тестов — запускать через Node из VS Code (команда в ARCHITECTURE.md, 12).
- Язык общения и интерфейса — русский.
