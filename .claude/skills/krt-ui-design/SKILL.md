# Дизайн-система сайта КРТ

Референс: `input_data/030926_Краткая презентация этапа 1 и ТОП 5 площадок 20261016-02.pdf`,
слайд «Формирование многоконтурной площадки». Визуальный язык прототипа имеет
приоритет над общими советами скилла `frontend-design`.

## Токены (web/css/tokens.css)

```css
:root {
  --ink: #00383D;            /* заголовки, основной текст */
  --ink-muted: #51676A;      /* подписи, пояснения */
  --line: #B2C2C4;           /* рамки панелей */
  --surface: #FFFFFF;

  --list-accent: #3D89A5;    /* номера в списках */
  --list-active: #77ACC0;    /* выбранная строка */

  --accent-rec: #E83273;     /* рекомендуемая: рамка, номера, цифры */
  --bg-rec: #FBDFE6;
  --bg-rec-soft: #FEF7F9;

  --accent-sel: #F9B000;     /* выбранная: рамка, номера, цифры */
  --bg-sel: #FFF0D6;
  --bg-sel-soft: #FFFBF5;

  /* легенда схем, цвета сняты с PDF площадок */
  --map-free: #77C8D2;
  --map-avar: #F192B0;
  --map-redev: #748FC9;
  --map-kept: #E8EAEB;
  --map-restricted: #00383E;
}
```

Жёлтый `#F9B000` на белом не проходит контраст для мелкого текста. Цифры
показателей крупные (≥ 24 px, жирные) — допустимо. Мелкий текст на жёлтом фоне
пишется цветом `--ink`.

## Типографика

- Atlas Grotesk (Regular 400, Medium 500, Bold 700), `.otf` в `web/fonts/`.
  Других весов нет: 600 и 800 не использовать. Без Google Fonts.
- Номера площадок крупные и жирные — это главный элемент навигации.
- Числа в показателях с `font-variant-numeric: tabular-nums`.

## Макет: сетка 3×3

```
┌──────────────┬──────────────┬──────────────┐
│ A1 Опорные   │ B1:B2        │ C1 Рекоменд. │
├──────────────┤ Опорная +    ├──────────────┤
│ A2:A3        │ схема        │ C2:C3        │
│ Добавьте     ├──────────────┤ Выбранная +  │
│ площадки     │ B3 Легенда   │ параметры    │
└──────────────┴──────────────┴──────────────┘
```

- CSS Grid с `grid-template-areas`, 3 равные колонки, 3 ряда, единый `gap`.
- Блок занимает целые ячейки или их объединения, никогда не половину.
- Меньше 1200 px — 2 колонки, меньше 768 px — 1 колонка в порядке
  A1, B1, C1, C2, A2, B3, C3. Без горизонтальной прокрутки.
- Подробности и состав блока C3 — в `docs/ARCHITECTURE.md`, раздел 8.

## Компоненты

- **Строка списка:** номер (крупно, `--list-accent`) + название мелко. Выбранная —
  фон `--list-active`. Неактивная (не помещается по площади) — приглушена,
  причина в подсказке и в `aria-disabled`.
- **Плашка комбинации:** рамка и заголовок цвета акцента, до 4 миниатюр с номерами
  в цветных бейджах, ниже 4 показателя. Три варианта: рекомендуемая (розовая),
  выбранная (жёлтая), расчётная (голубая, `--accent-opt` / `--bg-opt`).
- **Номер площадки** в миниатюре — цветной бейдж в правом верхнем углу, «×» — в правом нижнем. Подписи площади на схемах нет.
- **Буква категории** в левом верхнем углу миниатюры, белым на тёмной плашке `--ink`:
  Н — нейтральная, О — обременение, В — вознаграждение (у опорной нет). В фильтрах
  букв нет. Площадки, добавленные оптимизацией: только обводка миниатюры.
- **Шапка плашки** — по сетке 4 миниатюр: название | пояснения (2 колонки) | кнопка
  («Перенести в выбранную», «Оптимизировать выбор», «Сбросить выбор») на всю 4-ю колонку.
  Предупреждение об индексе — строкой пояснений. Плашка уже 530 px — название и кнопка
  в строку, пояснения под ними.
- **Показатель:** подпись мелко (`--ink-muted`), значение крупно цветом акцента.
- **Невалидный индекс (IP ≤ 1):** значение остаётся, рядом текст
  «Не проходит методику: индекс должен быть строго больше 1». Не полагаться только на цвет.
- Подпись показателя — «Индекс инвестиционного потенциала», не «Индекс».

## Форматы чисел (ru-RU, `Intl.NumberFormat`)

| Показатель | Формат | Пример |
|---|---|---|
| Индекс | 2 знака; проходит ли — только словами из `isIpValid` | 1,28 |
| Площадь участков, га | 1 знак | 38,9 |
| Градостроительный потенциал, тыс. м² | целое | 288 |
| Аварийное жильё, тыс. м² | 1 знак | 17,9 |

## Тексты

- Предложения с заглавной буквы, без КАПСА в подписях (в прототипе заголовки
  панелей капсом — допустимо только для них, как фирменный элемент).
- Кнопки и действия глаголом: «Добавить площадку», «Сбросить выбор».
- Ошибка объясняет, что случилось и что делать: «Площадка 30.2 не помещается:
  осталось 8,9 га из 45».
- Под заголовком рекомендуемой плашки: «Часть оптимального разбиения всех
  площадок: 68 из 80 без повторов».

## Доступность

- Списки — нативные `<button>` или `<input type="checkbox">`, работают с клавиатуры,
  видимый фокус.
- `alt` у схем: «Схема территории площадки 11.2».
- `prefers-reduced-motion` отключает анимации.
- Контраст текста ≥ 4.5:1.
