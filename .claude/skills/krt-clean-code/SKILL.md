# Чистый код проекта КРТ

## Принципы

- **Меньше кода — меньше ошибок.** Перед добавлением абстракции, класса,
  библиотеки или файла спроси: можно ли без этого? Один экран сайта не нуждается
  во фреймворке, роутере, менеджере состояния, сборщике.
- **Разделение слоёв:**
  - `web/js/domain/` — чистые функции без DOM, `fetch`, глобалов. Вход — данные,
    выход — данные. Только здесь формулы методики.
  - `web/js/ui/` — только отрисовка. Никаких вычислений показателей.
  - `web/js/state.js` — состояние и URL. `main.js` — связывает всё вместе.
- **Одно место для каждого правила.** Лимит 45 га, максимум 4 добавленных,
  порог IP — константы в `domain/`, продублированы только в Python-методике.
  Признак `addable` вычисляется при сборке данных.
- **Состояние минимально:** `{ anchorId, selectedIds }`. Производные значения
  вычисляются, а не хранятся.

## JavaScript

- ES-модули, `// @ts-check` в начале файла, JSDoc-типы на экспортируемых функциях.
- `const` по умолчанию, никаких `var`. Строгое сравнение `===`.
- Функции короткие (ориентир ≤ 30 строк), имена на английском, отражают предметную
  область: `integralIp`, `isIpValid`, `remainingAreaHa`.
- Числа в UI форматируются только через `domain/format.js` (`Intl.NumberFormat('ru-RU')`).
- Проверка `IP > 1` — в целых числах:
  `Σ (round(ip*100) - 100) * round(area*10) > 0`. Не сравнивать float с 1.
- Нет закомментированного кода, `console.log` в коммитах, мёртвых экспортов.

## Python (tools/)

- Переиспользовать `krt_optimizer.data_repository.SiteRepository` для чтения Excel,
  не писать второй парсер.
- Скрипт сборки падает с понятным сообщением при любой несогласованности данных:
  нет картинки, лишний ID, расхождение пересчёта с Excel.
- `krt_optimizer/` не изменять: методика закрыта.

## Тесты

- Каждая формула в `domain/` покрыта тестом `node --test` на golden cases из
  `tests/golden_cases.json`, которые генерирует Python из той же методики.
- Граничные случаи обязательны: IP ровно 1 (15.3, 19.1, 20.1), площадь ровно
  45 га, опорная 31.4 > 45 га, пустой выбор, 4 добавленных.

## Ревью

- Изменил архитектуру или контракт данных → обнови `docs/ARCHITECTURE.md`.
