## Ассистент

Изучил исходный массив из 80 площадок и проверил выполнимость условий.

Выполнить все условия одновременно в исходной постановке **не
получается**. Ключевое ограничение --- требование, чтобы каждая из 80
площадок вошла ровно один раз в комбинации, каждая комбинация имела
интегральный IP \> 1.

Площадь-взвешенный индекс инвестиционного потенциала всего массива
составляет примерно **0,9673**, то есть ниже 1. Если все 80 площадок
должны быть распределены между непересекающимися комбинациями и у каждой
комбинации средневзвешенный IP должен быть \>1, то средневзвешенный IP
всего объединенного набора также должен быть \>1. Поэтому полный охват
80/80 математически невозможен.

Корректная постановка глобальной задачи --- **максимизировать количество
уникальных площадок, вошедших в допустимые комбинации**, сохраняя IP
\>1, отсутствие повторений и остальные критерии как последующие
приоритеты.

При такой постановке получен набор из **25 площадок в 5 комбинациях по 5
площадок**:

1.  `31.4 + 26.2 + 33.2 + 16.1 + 19.2`, IP ≈ **1,0234**
2.  `2.2 + 32.3 + 13.1 + 18.3 + 18.1`, IP ≈ **1,00364**
3.  `7.1 + 24.2 + 13.2 + 20.4 + 21.3`, IP ≈ **1,0323**
4.  `1.2 + 20.2 + 32.1 + 27.3 + 27.5`, IP ≈ **1,0383**
5.  `31.3 + 23.1 + 24.1 + 34.2 + 26.1`, IP ≈ **1,00297**

Парето-отбор на этом этапе применялся как жесткий предварительный фильтр
по предельным эффектам относительно опорной площадки: аварийный фонд ↑,
новая жилая застройка ↑, прочая сносимая застройка ↓. После него
выполнялась глобальная оптимизация без повторений.

## Пользователь

что значит причина "не вошла в глобально оптимальный набор"?

## Ассистент

Это означает не то, что площадка сама по себе плохая или обязательно не
проходит IP \> 1.

Формулировка означает, что на этапе формирования **единого набора
непересекающихся комбинаций** модель выбрала другие сочетания. Площадка
может иметь допустимые варианты, но они пересекаются по другим площадкам
с комбинациями, которые позволяют получить лучший глобальный результат.

Более точные причины невхождения лучше разделять: 1. не проходит
ограничение по площади; 2. не входит ни в одну комбинацию, прошедшую IP
\>1 и Парето-отбор; 3. имеет допустимые комбинации, но не включена в
итоговый набор по результатам глобальной оптимизации из-за пересечения с
более приоритетными комбинациями.

3.  Рассчитываются предельные эффекты.

    комбинациях, затем учитывается Парето и последовательно
    оптимизируются три эффекта.

## Ассистент

После всех жёстких условий модель установила, что **максимум
одновременно можно включить 68 площадок**. Каждая площадка может
использоваться только один раз.

Оставшиеся **20.2, 27.3, 27.5, 27.6 и 30.2** сами по себе не запрещены
условием 45 га. Но у них **IP = 0**, поэтому самостоятельно они
существовать не могут --- их нужно присоединить к достаточно сильной
опорной площадке, чтобы итоговый IP комбинации остался \>1.

Возникает конкуренция за сильные площадки. Условно:

> Опорная А + площадки B + C + D → IP \>1 и охвачено 4 площадки.\
> Если вместо D включить проблемную 27.5, IP может упасть ≤1. Тогда
> приходится убрать ещё B или C либо добавить другую сильную площадку. В
> итоге включение 27.5 позволяет включить её саму, но может привести к
> выпадению нескольких других площадок.

Поэтому модель сравнивает не «хорошая ли площадка 27.5», а **сколько
всего уникальных площадок удастся разместить**, если попытаться включить
её.

Для строгой диагностики можно принудительно включать каждую из этих
площадок отдельно и заново максимизировать охват.
