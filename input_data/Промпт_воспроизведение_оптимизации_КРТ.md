# Промпт: воспроизведение оптимизации комбинаций площадок КРТ

Тебе передан Excel-файл `параметры площадок(1).xlsx`. Выполни расчет строго по методике ниже. Не меняй определения, порядок фильтров и приоритеты. Не используй жадный выбор комбинаций. Требуется глобальная оптимизация.

## Входные столбцы

- `Номер площадки КРТ`
- `Аварийный жилой фонд, кв.м`
- `СПП прочей сносимой застройки, кв.м`
- `Размер территории, га`
- `СПП новой жилой застройки, кв.м`
- `Индекс инвестиционного потенциала`
- `Категория`

Категории включают `опорная`, `вознаграждение`, `нейтральная площадка`, `обременение`.

## 1. Формирование кандидатов

### Обычные комбинации
Сгенерируй все комбинации из 1–5 площадок, содержащие **ровно одну** площадку категории `опорная`. Остальные элементы комбинации должны быть неопорными.

Для обычной комбинации:
- суммарная площадь `<= 45 га`;
- каждая площадка может позднее использоваться в итоговом наборе не более одного раза.

### Крупные площадки
Если площадь отдельной площадки `>45 га`, она не может входить в обычную комбинацию. Но она допускается как самостоятельная комбинация из одной площадки, если ее собственный IP строго `>1`. Категория такой крупной площадки значения не имеет.

## 2. Интегральный IP

Для обычной комбинации рассчитай:

`IP_comb = sum(IP_i * Area_i) / sum(Area_i)`

Оставь только комбинации, для которых `IP_comb > 1`. Равенство 1 не проходит.

Для крупной самостоятельной площадки используй ее собственный IP и также требуй `IP > 1`.

## 3. Предельные эффекты

Для обычной комбинации относительно ее опорной площадки:

- `Δ аварийного фонда = сумма аварийного жилого фонда дополнительных площадок`;
- `Δ новой жилой застройки = сумма СПП новой жилой застройки дополнительных площадок`;
- `Δ прочей сносимой застройки = сумма СПП прочей сносимой застройки дополнительных площадок`.

Для самостоятельной крупной площадки все Δ = 0.

## 4. Глобальная оптимизация

Введи бинарную переменную `x_j` для каждого допустимого кандидата.

Для каждой исходной площадки i:
`sum(x_j для всех j, содержащих i) <= 1`.

### Лексикографические цели
Оптимизируй строго последовательно. После каждого шага зафиксируй достигнутый оптимум жестким ограничением и только затем запускай следующий шаг.

1. **Максимизировать охват уникальных площадок**:
   `max sum(size_j * x_j)`.
2. При максимальном охвате **минимизировать максимальное количество площадок в обычной комбинации**.
3. При тех же значениях предпочесть **Парето-эффективное глобальное решение** по направлениям:
   - суммарный Δ аварийного фонда — max;
   - суммарный Δ новой жилой застройки — max;
   - суммарный Δ прочей сносимой застройки — min.
   Парето здесь НЕ является предварительным фильтром кандидатов.
4. Затем последовательно:
   - максимизировать суммарный Δ аварийного фонда;
   - максимизировать суммарный Δ новой жилой застройки;
   - минимизировать суммарный Δ прочей сносимой застройки.

Не допускай ухудшения более высокого приоритета ради более низкого.

## 6. Проверки перед выдачей результата

Обязательно:
1. Проверь для каждой обычной комбинации площадь `<=45 га`.
2. Пересчитай ее интегральный IP по исходному Excel и проверь `>1`.
3. Проверь, что крупные самостоятельные площадки имеют площадь `>45 га` и собственный IP `>1`.
4. Проверь отсутствие повторов ID.
5. Проверь, что всего охвачено 68 уникальных площадок.
6. Выведи таблицу с составом, площадью, интегральным IP и тремя предельными эффектами.
7. Если твой математический оптимизатор получает другой набор при тех же значениях всех целевых функций, сообщи, что найден альтернативный эквивалентный оптимум, и сравни его с контрольным набором. Не подменяй это утверждением, что контрольный набор ошибочен, пока не проверены все ограничения и порядок лексикографических целей.
